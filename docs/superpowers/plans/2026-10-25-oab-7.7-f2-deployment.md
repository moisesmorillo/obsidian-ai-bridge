## Approach and decisions

Keep the current OAuth provider, verified Access assertions, SQLite Vault authority, and R2 adapter. No application behavior changes form part of this scope revision.

OpenTofu controls routing and Access. The Worker configuration contains bindings and the canonical `SERVICE_ORIGIN`, but no route or custom-domain declaration.

The infrastructure must protect `/authorize`, its descendants, `/owner`, and its descendants. The owner policy permits only `mmorillodev@pm.me` through Email OTP.

Worker assertion verification still checks signature, issuer, audience, expiration, and exact owner subject. Access protection does not replace these checks.
